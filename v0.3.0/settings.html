Settings¶

cns.settings is the public settings object for package-wide cnsplots defaults. Update its attributes to change styling, export behavior, setup helpers, figure helpers, and multipanel defaults for subsequent plotting calls.

Changes to cns.settings are global until you either call cns.settings.reset() or temporarily override a subset of values inside cns.settings.context(...).

See the API landing page for the broader API reference and the runnable settings example for a gallery-backed tour of these defaults in practice.

Quickstart¶

Inspect the current settings object:

import cnsplots as cns

print(cns.settings)

Assign a new global default:

cns.settings.title_fontsize = 10
cns.settings.palette_qual = "Set2"

Reset back to the package defaults:

cns.settings.reset()

Apply temporary overrides inside a context manager:

with cns.settings.context(
    palette_qual="Dark2",
    figure_width=200,
    figure_height=120,
):
    ...

Methods¶

CNSSettings.reset()[source]¶

Reset all settings to their package defaults.

This mutates the shared cns.settings object in place and restores every documented setting to the default declared by cnsplots.

Return type:

None

CNSSettings.context(**kwargs)[source]¶

Temporarily override settings within a context manager.

Parameters:

**kwargs (Any) – Setting names and temporary values to apply to cns.settings for the duration of the with block.

Yields:

CNSSettings – The shared settings object with the temporary overrides applied.

Raises:

AttributeError – If any provided key is not a valid public setting name.

Return type:

Generator[CNSSettings, None, None]

Notes

Previous values are restored after the context exits, even if an exception is raised inside the block.
