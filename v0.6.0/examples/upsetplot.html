UpSet Plot¶

Create UpSet plots for visualizing set intersections.

UpSet plots are an alternative to Venn diagrams that scale better for many sets (>3). They show all possible intersections as a matrix with bar charts indicating intersection sizes.

Load packages¶

import random

import cnsplots as cns

Create sample sets¶

sets = {
    "A": ["a", "b", "c", "d"],
    "B": ["c", "d", "e", "f"],
    "C": ["b", "d", "f", "g"],
    "D": ["a", "e", "g", "h"],
}

Basic UpSet plot¶

Show all set intersections.

axes = cns.upsetplot(sets, subset_size="count")
axes["intersections"].set_title("Basic UpSet Plot")
