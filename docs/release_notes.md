# Release Notes

Published GitHub releases appear here automatically, so the docs stay in sync with the latest shipped version without waiting for a docs rebuild.

You can also browse the full release archive on [GitHub Releases](https://github.com/faridrashidi/cnsplots/releases).

```{raw} html
<div
  class="release-notes-page js-release-notes"
  data-user="faridrashidi"
  data-repo="cnsplots"
>
  <div
    class="release-notes-status js-release-notes-status"
    data-state="loading"
    aria-live="polite"
  >
    Loading published releases from GitHub...
  </div>
  <div class="release-notes-list js-release-notes-list" hidden></div>
  <noscript>
    <p>
      Release notes require JavaScript on this page. You can still read every
      release on
      <a href="https://github.com/faridrashidi/cnsplots/releases">GitHub Releases</a>.
    </p>
  </noscript>
</div>
```
