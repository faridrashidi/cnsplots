API¶

Import cnsplots as:

import cnsplots as cns

Plotting Functions¶

Every plotting function accepts a keyword-only ax argument for composition inside an existing Matplotlib layout. Most return the target matplotlib.axes.Axes; heatmapplot, dotplot, upsetplot, and vennplot instead preserve their backend-native results: ClusterMapPlotterNew, DotClustermapPlotterNew, a dictionary of panel axes, and a matplotlib-venn diagram object, respectively.

Distribution & Comparison Plots¶

boxplot

Create a box plot showing the distribution of a continuous variable across categories.

violinplot

Create a violin plot showing the distribution of a continuous variable.

stripplot

Create a strip plot showing individual data points with optional summary statistics.

barplot

Create a bar plot showing mean values across categories with optional statistics.

lollipopplot

Create a lollipop plot showing values across categories.

dumbbellplot

Create a dumbbell plot comparing two numeric values per category.

histplot

Create a histogram plot (wrapper around seaborn.histplot).

distplot

Create a distribution plot combining histogram and kernel density estimate.

kdeplot

Create a kernel density estimate plot with optional mode annotation.

ridgeplot

Create a ridge plot (joyplot) showing distributions across categories.

Scatter & Regression Plots¶

scatterplot

Create a scatter plot with automatic legend size correction.

regplot

Create a regression plot with linear fit and correlation statistics.

lineplot

Create a line plot (wrapper around seaborn.lineplot).

slopeplot

Create a slope plot showing paired changes between two conditions.

Heatmaps & Matrix Plots¶

heatmapplot

Create a clustered heatmap with optional annotations and dendrograms.

dotplot

Create a dot plot matrix with color and size encodings.

confusionplot

Create a confusion matrix heatmap with optional classification metrics.

Categorical & Proportion Plots¶

stackplot

Create a stacked bar plot showing categorical distributions.

pieplot

Create a pie chart showing categorical proportions.

donutplot

Create a donut chart showing categorical proportions.

vennplot

Create a Venn diagram for 2 or 3 sets.

upsetplot

Create an UpSet plot for visualizing set intersections.

sankeyplot

Create a Sankey diagram showing flows across categorical variables.

Survival Analysis Plots¶

survivalplot

Create a Kaplan-Meier survival plot with statistical comparisons.

cumulativeincidenceplot

Create a cumulative incidence plot for competing risks analysis.

Genomics & Statistical Plots¶

volcanoplot

Create a volcano plot for differential expression analysis.

gseaplot

Create a Gene Set Enrichment Analysis (GSEA) dot plot.

rocplot

Create a receiver operating characteristic (ROC) curve plot.

qqplot

Create a quantile-quantile (Q-Q) plot to assess normality.

forestplot

Create a forest plot from a results table or fitted model.

Specialized Plots¶

phyloplot

Create a phylogenetic tree plot with associated heatmaps.

placeholderplot

Create a stylized placeholder panel for figure layout mockups.

Statistical Models¶

CoxModel

Cox proportional hazards regression model for survival analysis.

LogisticModel

Logistic regression model with cross-validation for binary classification.

prerank

Perform pre-ranked Gene Set Enrichment Analysis (GSEA).

Figure & Layout Utilities¶

figure

Initialize a new figure with custom size and styling.

savefig

Save the current figure to a file, creating directories if needed.

multipanel

Create multi-panel figures with flexible panel sizes and margins.

add_panel_label

Add a panel label (e.g., 'A', 'B', 'C') to the current axes.

take_legend_out

Move the legend outside the plot area to the upper-left of the right margin.

Example Datasets¶

The gallery datasets are bundled with cnsplots, so loading them does not require network access.

load_dataset

Load a packaged example dataset without network access.

get_showcase_data

Load deterministic showcase datasets and optional packaged images.

Configuration & Setup¶

setup_matplotlib

Configure matplotlib with publication-quality default styling.

setup_scanpy

Configure matplotlib and scanpy with consistent publication-quality styling.

setup_ax

Apply publication-quality styling to a specific matplotlib axes.

setup_ggplot

Generate R ggplot2 theme code matching cnsplots styling.

Settings¶

cnsplots exposes its package-wide defaults through cns.settings. Use it to inspect current defaults, set global styling and helper behavior, restore package defaults with cns.settings.reset(), or apply temporary overrides with cns.settings.context(...).

print(cns.settings)
cns.settings.title_fontsize = 10

with cns.settings.context(palette_qual="Dark2", figure_width=200):
    ...

cns.settings.reset()

See the settings reference for the full catalog of settings and the runnable settings example for end-to-end usage.
