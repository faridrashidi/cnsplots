# Packaged data provenance and notices

This audit identifies the sources and known redistribution terms of the example
resources distributed with cnsplots. The cnsplots software license does not grant
additional rights to third-party data. There is no common license covering all
of these resources. Where an original data grant could not be verified, that
limitation is recorded below rather than assigning a license by inference.

Audited on 2026-09-07. All five CSV files in `cnsplots/datasets/_data/` are
byte-for-byte identical to the corresponding files in
[seaborn-data revision 71e2436a092d714350de0fc409ca8a8714e7e78f][seaborn-data]
(2024-01-12). This is a verified content match, not a recorded download revision.
They were added to cnsplots in
[commit 9dad1718f97181c8f3c0c48ee1e0ed798d6f5eb1][import-commit].
The [upstream source list][seaborn-sources] identifies several original sources;
the seaborn-data repository does not declare a common data license.

These CSVs contain third-party observations, not data generated by cnsplots.
`load_dataset()` reads each file with `pandas.read_csv`, including its usual type
inference and missing-value handling, and returns a fresh frame. The additional
loader transformations are described per dataset below. Stored CSV bytes are
unchanged.

## Iris

- Bundled file: [iris.csv][iris-csv], 150 rows.
- Original source: [UCI Iris dataset][iris-source]. Attribution: Fisher, R.
  (1936). *Iris* [Dataset]. UCI Machine Learning Repository.
  <https://doi.org/10.24432/C56C76>.
- Terms: UCI expressly distributes this dataset under
  [Creative Commons Attribution 4.0 International][cc-by]. Redistributors must
  preserve appropriate credit, the license link, and an indication of changes.
- Upstream representation: descriptive column headers and species names without
  the `Iris-` prefix. The numeric values and row order match `bezdekIris.data`
  from UCI's download, including the sample 35 and 38 corrections documented by
  UCI. cnsplots performs no additional dataset-specific transformation.

## Penguins

- Bundled file: [penguins.csv][penguins-csv], 344 rows.
- Original data: Kristen B. Gorman and Palmer Station Antarctica LTER,
  collected in 2007-2009. The [palmerpenguins data reference][penguins-source]
  identifies the Environmental Data Initiative records for Adélie (version 5),
  Gentoo (version 5), and Chinstrap (version 6) penguins and their dataset DOIs.
- Scientific attribution: Gorman, K. B., Williams, T. D., and Fraser, W. R.
  (2014). *Ecological Sexual Dimorphism and Environmental Variability within a
  Community of Antarctic Penguins (Genus Pygoscelis)*. PLoS ONE 9(3): e90081.
  <https://doi.org/10.1371/journal.pone.0090081>.
- Curated by Allison Marie Horst, Alison Presmanes Hill, and Kristen B. Gorman
  in palmerpenguins; package citation: <https://doi.org/10.5281/zenodo.3960218>.
- Terms: the [primary data introduction][penguins-terms] explicitly states that
  the data are available under [CC0 1.0 Universal][cc0]. Attribution above is
  retained for scientific provenance; it is not an additional license condition.
- Upstream representation: seaborn imported `penguins_size.csv` from
  `allisonhorst/penguins`, renamed the file to `penguins.csv`, and renamed culmen
  columns to bill columns. This seven-column snapshot lacks the `year` column
  present in current palmerpenguins. cnsplots title-cases `sex` values.

## Tips

- Bundled file: [tips.csv][tips-csv], 244 rows.
- Source: the [reshape2 tips documentation][tips-source] credits Bryant, P. G.
  and Smith, M. (1995). *Practical Data Analysis: Case Studies in Business
  Statistics*. Homewood, IL: Richard D. Irwin Publishing. The observations
  describe tips recorded by a waiter at one restaurant.
- Distribution terms: reshape2's [DESCRIPTION][reshape-description] declares
  `MIT + file LICENSE`; its [copyright file][reshape-license] names Hadley
  Wickham, 2008-2016. The complete MIT notice for that distribution appears below.
  A separate redistribution grant for the original Bryant and Smith data has
  not been verified; reshape2's package declaration is not presented as proof
  of the original data rights.
- cnsplots converts these columns to categoricals with these category sequences:
  `day`: Thur, Fri, Sat, Sun; `sex`: Male, Female; `time`: Lunch, Dinner;
  `smoker`: Yes, No. No numerical values are changed.

## Flights

- Bundled file: [flights.csv][flights-csv], 144 rows.
- Original series: [AirPassengers][flights-source], monthly international airline
  passenger totals in thousands, 1949-1960. The R documentation credits Box,
  G. E. P., Jenkins, G. M., and Reinsel, G. C. (1994). *Time Series Analysis:
  Forecasting and Control*, third edition. Prentice Hall.
- Upstream representation: the [seaborn processing script][flights-process]
  reads `AirPassengers.csv`, derives years and full month names from fractional
  time, renames counts to `passengers`, and drops the source index/time columns.
  cnsplots abbreviates months to three characters and makes them categorical
  in their first-appearance order.
- Terms unresolved: the cited sources do not state a dataset-specific
  redistribution grant. R's software license is not assumed to license the
  original series. Permission for the underlying data has not been verified.

## fMRI

- Bundled file: [fmri.csv][fmri-csv], 1,064 rows.
- Original source: [Waskom_CerebCortex_2017][fmri-source], the analysis repository
  for Waskom, M. L., Frank, M. C., and Wagner, A. D. (2017). *Adaptive engagement
  of cognitive control in context-dependent decision-making*. Cerebral Cortex.
  <https://doi.org/10.1093/cercor/bhv333>.
- Distribution notice: the [source README][fmri-source] supplies BSD-3-Clause
  terms, copyright 2015 Michael Waskom; its complete notice is retained below.
  The README expressly describes this as a code license. Its applicability to
  the derived CSV, and a separate original data grant, have not been verified.
- Upstream changes include column renaming and event sorting. cnsplots performs
  no additional dataset-specific transformation.

## Showcase images

The three identified images are third-party figure assets; the fourth image's
origin is unknown. None is generated by `get_showcase_data()`. All four WebP
files were added in
[commit 1284f705fa149f4bc1a1422cdacec09d76723504](https://github.com/faridrashidi/cnsplots/commit/1284f705fa149f4bc1a1422cdacec09d76723504)
(2026-03-17) and moved unchanged into `cnsplots/datasets/_data/showcase/` in the
CSV import commit above. Their original acquisition URLs and conversion settings
were not recorded. Sources below were identified by visual comparison with the
original publication figures. Cropping and WebP encoding predate the import;
the precise cropping/resampling procedure is unknown. The loader returns the
directory; the showcase decodes and scales the images for display without
changing the packaged bytes.

### image1.webp and image2.webp

- Source: Xue, R. et al. (2022). *Liver tumour immune microenvironment subtypes
  and neutrophil heterogeneity*. Nature 612, 141-147.
  <https://doi.org/10.1038/s41586-022-05400-x>.
- `image1.webp` (750 x 1200): liver photographs from
  [Figure 4f](https://www.nature.com/articles/s41586-022-05400-x/figures/4),
  cropped to the Isotype and Anti-Ly6G photographs, excluding the bar charts.
- `image2.webp` (692 x 612): the top TIME-IE microscopy image from
  [Figure 2f](https://www.nature.com/articles/s41586-022-05400-x/figures/2),
  cropped to exclude the lower magnified inset.
- Publisher copyright notice: "2022 The Author(s), under exclusive licence to
  Springer Nature Limited". The original article's
  [Rights and permissions](https://www.nature.com/articles/s41586-022-05400-x#rightslink)
  identifies exclusive publisher rights, not an open redistribution license.
  No separate permission record for these packaged crops was found in cnsplots.
  Attribution here does not establish redistribution permission; that record
  remains unresolved. These images are not relicensed under cnsplots' BSD terms.

### image3.webp

- Source: Ma, L., Hernandez, M. O., Zhao, Y. et al. (2019). *Tumor Cell
  Biodiversity Drives Microenvironmental Reprogramming in Liver Cancer*.
  Cancer Cell 36(4), 418-430.e6.
  <https://doi.org/10.1016/j.ccell.2019.08.007>.
- `image3.webp` (1500 x 753) reproduces the eight histology micrographs in
  [Figure 2E](https://pmc.ncbi.nlm.nih.gov/articles/PMC6801104/#F2), cropped
  from the full figure and stored in WebP format.
- Terms: the [publisher PDF hosted by the National Cancer Institute](https://ccr.cancer.gov/sites/default/files/pubs-files/Tumor%20Cell%20Biodiversity%20Drives%20Microenvironmental%20Reprogramming%20in%20Liver%20Cancer.pdf)
  identifies Elsevier Inc. as publisher and states CC BY 4.0 on page 418.
  Under [CC BY 4.0][cc-by], retain the attribution, source and license links,
  and this indication of cropping/format changes when redistributing the image.

### image4.webp

- `image4.webp` (360 x 320) is the four-strip western blot displayed in the
  showcase. Its original creator, publication, source URL, and license have
  not been established. The image has no embedded attribution metadata and the
  import commit gives no source. Its import history above is the only verified
  provenance; any earlier modifications are unknown.
- Terms unresolved: no redistribution permission record was found. The
  cnsplots software license is not evidence of rights to this image.

## Synthetic showcase fields

`get_showcase_data()` loads the Iris and Tips snapshots above. The remaining
fields are generated by cnsplots' BSD-licensed `datasets/gallery.py`: simulated
survival and competing-risk records, volcano and prediction scores, gene sets,
paired measurements, forest-plot inputs, and fixed confusion/line/overlap data.
These are demonstrations, not measured biological or patient observations.
The code uses a local NumPy generator seeded with 42. Gaussian blobs come from
Scanpy's `datasets.blobs()` (scikit-learn `make_blobs`, default seed 0); cnsplots
adds artificial annotations, subtracts the matrix-wide mean, and transposes it.
Detailed field-by-field transformations are described in the
[example data guide](https://github.com/faridrashidi/cnsplots/blob/main/docs/datasets.md).

## Outstanding provenance records

This audit does not establish original data grants for Tips, Flights, or fMRI,
nor image redistribution permission for `image1.webp`, `image2.webp`, or
`image4.webp`. The original source of `image4.webp` is also unresolved. Maintainers
should attach verifiable source/permission records to the
[provenance issue](https://github.com/faridrashidi/cnsplots/issues/178) before
treating those entries as cleared. Any replacement or removal of resources
requires a separately reviewed change; this documentation preserves the
existing bytes and behavior.
